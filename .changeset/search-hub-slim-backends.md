Search Hub now supports only Exa, Tavily, Firecrawl, and Parallel. `web_search` no longer accepts `backend`; combine is model-only and off by default. `web_read` no longer accepts `reader`. Old backend names are no longer valid, and Firecrawl remains the keyless search fallback.

The Ollama Cloud quota card now supports the new credit-based plans that report only a monthly usage window instead of session and weekly windows. Any of the three windows can now be shown on its own, the monthly window note shows recent spend when the API reports it, and the quota dashboard lists the top five per-model request counts under the Ollama monthly window.

Add a standalone adversarial review extension. `/adversarial-review` runs a hardened fetch-aware Git preflight before model selection: it infers feature-branch versus default-branch targets, asks TUI users about ambiguous or risky states (including `main`/`master` ambiguity), fails headless ambiguity loudly, disables repository/environment fetch execution hooks and helpers, binds the decision to HEAD/status/ref/patch fingerprints across model selection and freezing, and supports explicit offline `--local`; then it freezes local, base, or range Git input and selects two to eight exact scoped model/thinking routes through either a TUI picker or explicit flags; validates every reviewer report; deterministically clusters findings; applies weighted or strict health and consensus gates; detects drift; and shows aggregate progress with explicitly confirmed whole-run Escape cancellation. A compatible installed protocol-v3 Subagents extension supplies shared queueing and FleetView; when it is absent or incompatible, the command automatically uses the same caller-owned execution core through a side-effect-free embedded backend, without adding Agent tools or Subagents UI. Optional refutation runs one fresh isolated refuter per blocking cluster and records contested evidence without removing findings. The final audit records backend/fallback reason plus routes/concurrency/waves and, outside print mode, is automatically handed to the current main model under fixed evidence-first, no-fix/no-commit instructions. Every non-TUI report/error is atomically persisted in a private standalone audit store independent of Pi's session flush policy; print/JSON operational failures also write control-safe stderr and set a non-zero process status. Frozen input now uses a 200 KiB / 5,000-line recommendation and a 1 MiB / 25,000-line absolute limit: TUI can approve a whole large target or show SHA-bound, non-empty `--range` replacements, headless runs require `--allow-large`, and approved large targets use 40 reviewer turns with 20/30-minute route/overall limits and 20 refuter turns with 10/30-minute limits, while ordinary limits remain unchanged. Hardening also covers raw Git blobs, disabled textconv/content filters/fsmonitor, binary/LFS/submodule limits, cancellable range-snapshot extraction with an abort-identity-checked minimal durable pre-freeze cancellation audit and separately classified workspace-cleanup failures, whole-graph symlink expansion checks with conservative Unicode/canonical Windows alias simulation before materialization, explicit run-stage Escape confirmation, narrow leading-prose plus single-JSON-fence parser compatibility, a 30-second Review-only embedded terminal deadline that retains frozen input on cleanup timeout, atomic-quarantine same-UID crash cleanup, strict UTF-8 raw-output bounds, durable renderer recovery, and compatibility/rollback guidance. The package is intentionally not included in the root extension bundle.

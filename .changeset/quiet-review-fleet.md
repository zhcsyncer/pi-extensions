Add a standalone adversarial review extension. `/adversarial-review` freezes local, base, or range Git input; selects two to eight exact scoped model/thinking routes through either a TUI picker or explicit flags; validates every reviewer report; deterministically clusters findings; applies weighted or strict health and consensus gates; detects drift; and shows aggregate progress with whole-run Escape cancellation. A compatible installed protocol-v3 Subagents extension supplies shared queueing and FleetView; when it is absent or incompatible, the command automatically uses the same caller-owned execution core through a side-effect-free embedded backend, without adding Agent tools or Subagents UI. Optional refutation runs one fresh isolated refuter per blocking cluster and records contested evidence without removing findings. The final audit records backend/fallback reason plus routes/concurrency/waves and, outside print mode, is automatically handed to the current main model under fixed evidence-first, no-fix/no-commit instructions. Print/JSON operational failures now persist an error audit, write control-safe stderr, and set a non-zero process status. Hardening also covers raw Git blobs, disabled textconv/content filters/fsmonitor, binary/LFS/submodule limits, atomic-quarantine same-UID crash cleanup, strict UTF-8 raw-output bounds, durable renderer recovery, and compatibility/rollback guidance. The package is intentionally not included in the root extension bundle.

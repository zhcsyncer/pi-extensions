Add a standalone adversarial review extension. `/adversarial-review` freezes local, base, or range Git input; selects two to eight exact scoped model/thinking routes through either a TUI picker or explicit flags; runs them through the caller-owned subagent protocol; validates every reviewer report; deterministically clusters findings; applies weighted or strict health and consensus gates; detects drift; shows aggregate progress with whole-run Escape cancellation; and emits an audited routes/concurrency/waves report without automatically triggering the main model. The package is intentionally not included in the root extension bundle.

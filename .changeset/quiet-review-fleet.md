Add a standalone adversarial review extension. `/adversarial-review` runs a hardened fetch-aware Git preflight before model selection: it infers feature-branch versus default-branch targets, asks TUI users about ambiguous or risky states (including `main`/`master` ambiguity), fails headless ambiguity loudly, disables repository/environment fetch execution hooks and helpers, binds the decision to HEAD/status/ref/patch fingerprints across model selection and freezing, and supports explicit offline `--local`; then it freezes local, base, or range Git input and selects two to eight exact scoped model/thinking routes through either a TUI picker or explicit flags; validates every reviewer report; deterministically clusters findings; applies weighted or strict health and consensus gates; detects drift; and shows aggregate progress with explicitly confirmed whole-run Escape cancellation. A compatible installed protocol-v3 Subagents extension supplies shared queueing and FleetView; when it is absent or incompatible, the command automatically uses the same caller-owned execution core through a side-effect-free embedded backend, without adding Agent tools or Subagents UI. Picker routes start disabled and first enable at `medium` or the nearest supported thinking level, while session-remembered and scope-pinned choices keep their constraints. Optional refutation runs one fresh isolated refuter per blocking cluster and records contested evidence without removing findings; TUI armed/running state, skip reasons, valid attempts, and contested counts are now explicit in the footer, completion notification, and collapsed or expanded report. The final audit records backend/fallback reason plus routes/concurrency/waves and, outside print mode, is automatically handed to the current main model under fixed evidence-first, no-fix/no-commit instructions. Every non-TUI report/error is atomically persisted in a private standalone audit store independent of Pi's session flush policy; print/JSON operational failures also write control-safe stderr and set a non-zero process status. Frozen input now uses a 200 KiB / 5,000-line recommendation and a 1 MiB / 25,000-line absolute limit: TUI can approve a whole large target or show SHA-bound, non-empty `--range` replacements, headless runs require `--allow-large`, and approved large targets use 40 reviewer turns with 20/30-minute route/overall limits and 20 refuter turns with 10/30-minute limits, while ordinary limits remain unchanged. Hardening also covers raw Git patch capture, disabled textconv/content filters/fsmonitor, binary/LFS/submodule limits, and committed-only ranges whose B endpoint must be reachable from the current named branch HEAD before model selection. Every range, including clean B=HEAD, gives all reviewers and refuters one extension-owned detached linked worktree at B without changing the original index, files, branch, or HEAD. Linked checkout creation enforces fixed 100,000-entry and 2 GiB raw logical-data prelimits, an additive 512 MiB + 2× raw-byte temporary-filesystem reserve, a deterministic common-Git admin/index reserve, and a live 512 MiB reset floor; it atomically records pending intent before race-free token-locked add, then uses a hardened non-recursive reset with hooks, configured filters/LFS smudge, live symlinks, CRLF conversion, submodule recursion, replace refs, optional locks, and inherited Git path/config environment disabled. Worktree-first cleanup removes and verifies only the exact token-proven registration, clears ownership state before deleting the run directory, and supports retry/TTL cleanup after final directory deletion fails; current-cwd/live-PID checks plus quarantine-time `.git` revalidation preserve substitutions and unproven worktrees without broad prune. Cancellation keeps abort-identity-checked minimal durable pre-freeze audit behavior and separately classified cleanup failures; the package also retains explicit run-stage Escape confirmation, narrow leading-prose plus single-JSON-fence parser compatibility, a 30-second Review-only embedded terminal deadline that retains frozen input and any detached worktree on cleanup timeout, strict UTF-8 raw-output bounds, durable renderer recovery, and compatibility/rollback guidance. The package is intentionally not included in the root extension bundle.

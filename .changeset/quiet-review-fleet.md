Add a standalone adversarial review extension. `/adversarial-review` freezes local, base, or range Git input; selects two to eight exact scoped model/thinking routes through either a TUI picker or explicit flags; runs them through the caller-owned subagent protocol; validates every reviewer report; deterministically clusters findings; applies weighted or strict health and consensus gates; detects drift; and shows aggregate progress with whole-run Escape cancellation. Optional refutation runs one fresh isolated refuter per blocking cluster and records contested evidence without removing findings. The final audited routes/concurrency/waves report is rendered compactly and, outside print mode, automatically handed to the current main model under fixed evidence-first, no-fix/no-commit adjudication instructions. The package is intentionally not included in the root extension bundle.

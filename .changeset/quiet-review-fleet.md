Add a standalone no-UI adversarial review extension. `/adversarial-review` freezes local, base, or range Git input; runs two to eight exact scoped model/thinking routes through the caller-owned subagent protocol; validates every reviewer report; deterministically clusters findings; applies weighted or strict health and consensus gates; detects drift; and emits a merged report without automatically triggering the main model. The package is intentionally not included in the root extension bundle.
